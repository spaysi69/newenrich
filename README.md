# ColdIQ LinkedIn Contact Lookup

A small, password-protected web app: paste one LinkedIn profile URL, call ColdIQ's Lima Data person-enrichment endpoint, and view/copy the response.

## Fast hosting: Render

1. Put this folder in a GitHub repository (do **not** commit your real `.env` file or API key).
2. In Render, choose **New + → Blueprint** and connect that repository. Render reads `render.yaml` and creates the web service.
3. In the service's Environment settings, add values for:
   - `COLDIQ_API_KEY`: your ColdIQ API key.
   - `APP_PASSWORD`: a long, unique password you'll use to sign into the app.
   `SESSION_SECRET` is generated by the Blueprint. Keep `COOKIE_SECURE=true` on the hosted HTTPS site.
4. Deploy, open the service URL, sign in with your app password, and paste a LinkedIn profile URL.

The free hosting option may sleep during inactivity, so the first request after a quiet period can take longer.

## Run locally

Requires Python 3.10+.

```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# macOS/Linux:
# source .venv/bin/activate
pip install -r requirements.txt
```

Set the environment variables before starting the app. For example, in macOS/Linux:

```bash
export COLDIQ_API_KEY="your-real-key"
export APP_PASSWORD="your-unique-app-password"
export SESSION_SECRET="a-long-random-secret"
export COOKIE_SECURE=false
python app.py
```

On Windows PowerShell, use `$env:COLDIQ_API_KEY="..."`, `$env:APP_PASSWORD="..."`, `$env:SESSION_SECRET="..."`, and `$env:COOKIE_SECURE="false"` instead. Then open http://127.0.0.1:5000.

## Behavior and costs

- Calls `POST https://api.coldiq.com/v1/limadata/enrich/person` with Bearer authentication.
- Work-email lookup is enabled by default. Phone lookup is optional and disabled by default because ColdIQ's marketplace page says it adds 10 credits if a phone is found.
- The app shows common contact fields when it can identify them, plus the complete JSON response and copy buttons.
- ColdIQ response fields and credit costs are controlled by your ColdIQ plan/API. Check your dashboard if a request fails or returns no contact details.
- Keep this app password-protected. Anyone who can use it could consume your ColdIQ API credits.

## Environment variables

| Variable | Required | Purpose |
|---|---|---|
| `COLDIQ_API_KEY` | Yes | Server-side ColdIQ API key |
| `APP_PASSWORD` | Yes | Password gate for the web app |
| `SESSION_SECRET` | Production | Signs browser sessions; use a unique random value |
| `COOKIE_SECURE` | Hosted HTTPS | Set `true` on hosted HTTPS; `false` for local HTTP |
